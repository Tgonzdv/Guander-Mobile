## 1. Introducción

Bienvenido/a a **Guander**.

Guander es una aplicación móvil diseñada para conectar a dueños de mascotas con lugares pet-friendly cercanos. A través de una interfaz moderna e intuitiva, podrás descubrir nuevos establecimientos, acumular **PetPoints** visitando lugares, canjear recompensas exclusivas y compartir tu experiencia con la comunidad.

Con Guander vas a poder explorar el mapa interactivo, escanear códigos QR en los comercios asociados para sumar puntos, revisar opiniones de otros usuarios y gestionar tu perfil desde la palma de tu mano.

---

## 2. Objetivo

Si bien esta aplicación fue desarrollada bajo un riguroso lineamiento de estándares de navegabilidad y experiencia de usuario, haciendo de la misma una herramienta intuitiva y autodidacta, a través de este manual vas a poder interiorizarte aún más sobre las funcionalidades del sistema, cómo utilizarlas y familiarizarte con los flujos disponibles.

Este documento se encuentra en desarrollo constante, ya que el mismo depende exclusivamente de la expansión y la implementación de nuevas funcionalidades pensadas y desarrolladas en base a las necesidades de la comunidad.

Nuevas actualizaciones o adhesiones a dicho documento serán comunicadas debidamente.

Esperamos sea de utilidad y estamos a disposición para cualquier consulta o sugerencia.

## 3. Requisitos del dispositivo

Para poder instalar y utilizar Guander correctamente, el dispositivo debe cumplir con los siguientes requisitos mínimos:

| Requisito            | Detalle                                |
|----------------------|----------------------------------------|
| Sistema operativo    | Android 7.0 (Nougat) o superior        |
| Versión de Android   | API 24 o superior                      |
| Conexión a internet  | Requerida para todas las funciones     |
| Cámara               | Requerida para el escáner QR           |
| GPS / Ubicación      | Requerida para el mapa de lugares      |
| Almacenamiento       | Al menos 50 MB libres                  |
| Cuenta Google        | Recomendada para inicio de sesión rápido |

**IMPORTANTE:** La aplicación requiere que el usuario conceda los siguientes permisos durante su uso:

- **Ubicación** – Para mostrar lugares pet-friendly cercanos en el mapa.
- **Cámara** – Para escanear códigos QR en los establecimientos.
- **Imágenes / Almacenamiento** – Para actualizar la foto de perfil.
- **Notificaciones** – Para recibir alertas de puntos, cupones y promociones.

En todo momento la aplicación solicitará estos permisos de forma contextual, es decir, al momento en que se requiera cada funcionalidad.

## 4. Instalación de la aplicación

### Descarga desde Google Play Store

1. Abrir la aplicación **Google Play Store** en el dispositivo Android.
2. En la barra de búsqueda, escribir **"Guander"**.
3. Seleccionar la aplicación en los resultados de búsqueda.
4. Presionar el botón **"Instalar"**.
5. Aguardar a que la descarga e instalación finalicen.
6. Una vez instalada, presionar **"Abrir"** o acceder al ícono de Guander desde la pantalla de inicio del dispositivo.

### Instalación manual (APK)

En caso de recibir el archivo de instalación directamente:

1. En el dispositivo, ingresar a **Configuración > Seguridad** y habilitar la opción **"Instalar aplicaciones de fuentes desconocidas"** (o "Instalar apps desconocidas", según la versión de Android).
2. Descargar el archivo `.apk` en el dispositivo.
3. Abrir el archivo descargado y seguir las instrucciones de instalación.
4. Una vez finalizada la instalación, el ícono de Guander aparecerá en la pantalla de inicio.

**IMPORTANTE:** Si el sistema solicita confirmación para habilitar instalaciones de fuentes externas, asegurarse de realizarlo únicamente desde fuentes confiables y conocidas.

## 5. Ingreso al sistema

Al abrir Guander por primera vez, el usuario será dirigido a la pantalla de inicio de sesión. La aplicación ofrece dos métodos de acceso.

### 5.1. Iniciar sesión con Google

Esta es la forma más rápida y recomendada de acceder a la aplicación.

1. Presionar el botón **"Continuar con Google"**.
2. El sistema mostrará el selector de cuentas de Google disponibles en el dispositivo.
3. Seleccionar la cuenta deseada.
4. El sistema validará las credenciales y redirigirá automáticamente al **Panel Principal (Dashboard)**.

**IMPORTANTE:** En caso de error al iniciar sesión con Google, verificar que:
- El dispositivo cuente con una cuenta de Google configurada.
- Exista conexión a internet activa.

En todo momento, la interfaz gráfica informará el estado y resultado de la acción solicitada.

### 5.2. Iniciar sesión con correo electrónico

1. Presionar el botón **"Ingresar con email"** para desplegar el formulario de acceso.
2. Completar los campos:
   - **Correo electrónico**
   - **Contraseña**
3. Presionar **"Iniciar sesión"**.
4. Si las credenciales son correctas, el sistema redirigirá al **Panel Principal (Dashboard)**.

### 5.3. Registro de nueva cuenta

En caso de no poseer una cuenta, el usuario puede registrarse directamente desde la pantalla de inicio de sesión.

1. Presionar el botón **"Ingresar con email"** para desplegar el formulario.
2. Completar los campos:
   - **Correo electrónico**
   - **Contraseña**
3. Presionar **"Registrarse"**.
4. El sistema creará la cuenta y redirigirá al **Panel Principal**.

**IMPORTANTE:** El sistema validará que el correo electrónico no se encuentre registrado previamente. En caso de existencia previa, el sistema mostrará una alerta indicando que ya existe una cuenta con ese correo.

### 5.4. Recuperación de contraseña

En caso de haber olvidado la contraseña:

1. En la pantalla de inicio de sesión, presionar el texto **"¿Olvidaste tu contraseña?"**.
2. El sistema mostrará un diálogo solicitando el correo electrónico asociado a la cuenta.
3. Ingresar el correo electrónico y confirmar.
4. Se enviará un correo con las instrucciones para restablecer la contraseña.

## 6. Panel principal (Dashboard)

Luego de autenticarse correctamente, el usuario ingresará al **Panel Principal**, que es el punto de partida de la experiencia en Guander.

Esta pantalla presenta:

- **Saludo personalizado** – Muestra el nombre o usuario del perfil autenticado junto a su foto de avatar.
- **PetPoints acumulados** – Contador con el total de puntos acumulados por el usuario.
- **Notificaciones recientes** – Listado de las últimas novedades y actividad de la cuenta (puntos obtenidos, canjes realizados, etc.).

### Navegación inferior

En la parte inferior de la pantalla se encuentra la **barra de navegación**, que permite acceder a las secciones principales de la aplicación:

| Ícono       | Sección                        |
|-------------|-------------------------------|
| Inicio      | Panel Principal (Dashboard)   |
| Mapa        | Mapa de lugares               |
| QR          | Escáner QR                    |
| Recompensas | Catálogo de recompensas       |
| Perfil      | Mi perfil                     |

Esta barra de navegación estará disponible en todas las pantallas principales de la aplicación.

## 7. Mapa de lugares

La sección de **Mapa** permite descubrir establecimientos pet-friendly cercanos a la ubicación del usuario.

Al ingresar por primera vez, la aplicación solicitará permiso de acceso a la ubicación del dispositivo. Este permiso es necesario para mostrar los lugares más cercanos.

La pantalla se divide en dos vistas:

- **Vista de mapa** – Muestra los lugares como marcadores sobre el mapa interactivo.
- **Vista de lista** – Muestra los lugares como tarjetas con información básica: nombre, categoría y distancia.

### 7.1. Filtros y búsqueda

En la parte superior de la pantalla se encuentra una barra de búsqueda y opciones de filtro:

- **Barra de búsqueda** – Permite buscar lugares por nombre o palabra clave.
- **Filtros por categoría** – Al presionar el selector de filtros, se desplegarán las subcategorías disponibles (por ejemplo: veterinarias, parques, hoteles, restaurantes, etc.).

Para aplicar un filtro:
1. Presionar el botón de filtros para desplegar las categorías.
2. Seleccionar la categoría deseada.
3. El mapa y la lista se actualizarán automáticamente mostrando solo los lugares que correspondan al filtro seleccionado.
4. Para volver a ver todos los lugares, seleccionar la opción **"Todos"**.

### 7.2. Vista de lista y mapa

- En la **vista de lista**, cada tarjeta de lugar muestra el nombre del establecimiento, categoría y distancia aproximada. Presionar sobre una tarjeta para ver el detalle completo del lugar.
- En la **vista de mapa**, presionar sobre un marcador abrirá un panel inferior con la información básica del lugar y un botón de acceso al detalle completo.

### 7.3. Detalle de un lugar

Al acceder al detalle de un lugar, el usuario encontrará:

- **Galería de imágenes** – Carrusel con fotos del establecimiento.
- **Información general** – Nombre, categoría, dirección y datos de contacto.
- **Botón para abrir en mapa externo** – Permite abrir la dirección en la aplicación de mapas del dispositivo.
- **Valoración promedio** – Puntuación otorgada por otros usuarios.
- **Comentarios y reseñas** – Opiniones de la comunidad sobre el establecimiento.
- **Formulario de comentario** – Si el usuario se encuentra autenticado, podrá dejar su propia valoración (estrellas) y un comentario.

**IMPORTANTE:** Para poder dejar un comentario o valoración, el usuario debe haber iniciado sesión en la aplicación.

## 8. Escáner QR

La sección de **Escáner QR** permite al usuario acumular **PetPoints** visitando los establecimientos asociados a Guander.

Al ingresar por primera vez, la aplicación solicitará permiso de acceso a la cámara del dispositivo. Este permiso es necesario para poder escanear los códigos QR.

### Cómo usar el escáner

1. Acceder a la sección **QR** desde la barra de navegación inferior.
2. Apuntar la cámara hacia el código QR ubicado en el establecimiento pet-friendly.
3. La aplicación detectará automáticamente el código y procesará la solicitud.
4. Si el escaneo es exitoso, el sistema mostrará un mensaje de confirmación indicando la cantidad de **PetPoints** acreditados.
5. Los puntos se reflejarán de inmediato en el contador del Panel Principal.

**IMPORTANTE:**
- Cada código QR solo puede ser escaneado una vez por día por el mismo usuario.
- Es necesario contar con conexión a internet activa para validar el escaneo y acreditar los puntos.
- En caso de error, la aplicación mostrará un mensaje descriptivo con el motivo del inconveniente.

## 9. Recompensas

La sección de **Recompensas** permite al usuario canjear los **PetPoints** acumulados por premios, descuentos y beneficios exclusivos de los establecimientos asociados.

La pantalla se divide en dos pestañas:

| Pestaña      | Descripción                                              |
|--------------|----------------------------------------------------------|
| Canjear      | Catálogo de recompensas disponibles para redimir         |
| Historial    | Registro de todos los canjes realizados previamente      |

En la parte superior se muestra el total de **PetPoints** disponibles del usuario.

### 9.1. Canjear recompensas

1. Acceder a la pestaña **"Canjear"**.
2. Utilizar la **barra de búsqueda** para encontrar una recompensa específica, o bien explorar el catálogo completo.
3. Utilizar el **selector de tienda/local** para filtrar las recompensas por establecimiento.
4. Presionar sobre la recompensa deseada para ver su detalle: descripción, costo en PetPoints y condiciones.
5. Si el usuario cuenta con los puntos suficientes, presionar el botón **"Canjear"**.
6. El sistema solicitará una confirmación antes de procesar el canje.
7. Una vez confirmado, los puntos serán deducidos del saldo del usuario y la recompensa quedará registrada en el historial.

**IMPORTANTE:** El sistema validará que el usuario cuente con el saldo de PetPoints necesario para realizar el canje. En caso de saldo insuficiente, el sistema mostrará una alerta informativa.

### 9.2. Historial de canjes

1. Acceder a la pestaña **"Historial"**.
2. Se mostrará el listado completo de todos los canjes realizados, con la siguiente información:
   - Nombre de la recompensa canjeada.
   - Fecha y hora del canje.
   - Cantidad de PetPoints utilizados.

## 10. Mi Perfil

La sección de **Perfil** permite al usuario gestionar su información personal y acceder a las configuraciones de la cuenta.

Al ingresar a esta sección, se mostrará:

- **Foto de perfil** (avatar del usuario).
- **Nombre completo** del usuario.
- **Correo electrónico** vinculado a la cuenta.
- **Total de PetPoints** acumulados.
- **Fecha de registro** en la plataforma.
- Opciones de navegación hacia las sub-secciones de perfil.

### 10.1. Editar perfil

1. Dentro de la sección Perfil, presionar la opción **"Editar perfil"**.
2. Se abrirá una nueva pantalla con los campos editables:
   - Nombre
   - Apellido
   - Correo electrónico
   - Teléfono
   - Domicilio
3. Actualizar los campos deseados y presionar **"Guardar"**.
4. El sistema validará los datos ingresados y confirmará la actualización.

**IMPORTANTE:** Modificar el correo electrónico puede afectar el acceso a la cuenta. Asegurarse de ingresar una dirección de correo válida y activa.

### 10.2. Cambiar foto de perfil

1. Dentro de la sección Perfil, presionar sobre la **foto de perfil** o el botón de edición de imagen.
2. El sistema solicitará permiso de acceso a la galería del dispositivo (si aún no fue concedido).
3. Seleccionar la imagen deseada desde la galería.
4. La imagen se cargará y actualizará automáticamente en el perfil.

## 11. Configuración de notificaciones

La aplicación permite gestionar de forma granular las notificaciones que el usuario desea recibir.

Para acceder a esta sección:
1. Ingresar a la sección **Perfil** desde la barra de navegación.
2. Seleccionar la opción **"Notificaciones"** en el menú de configuración.

Las opciones disponibles son:

| Notificación             | Descripción                                                     | Activado por defecto |
|--------------------------|-----------------------------------------------------------------|----------------------|
| Notificaciones generales | Switch maestro que controla todas las notificaciones            | Sí                   |
| Mis puntos               | Alertas al acumular o utilizar PetPoints                        | Sí                   |
| Cupones                  | Avisos cuando haya cupones próximos a vencer                    | Sí                   |
| Nuevos lugares           | Notificaciones cuando haya nuevos lugares pet-friendly cercanos | No                   |
| Promociones              | Descuentos especiales y ofertas de temporada                    | Sí                   |

**Cómo gestionar las notificaciones:**

- El **switch maestro** ("Notificaciones generales") controla el estado de todas las notificaciones. Al desactivarlo, todas las notificaciones quedarán suspendidas.
- Cada notificación individual puede ser activada o desactivada de manera independiente, siempre que el switch maestro esté habilitado.
- Los cambios se aplican de forma inmediata.

## 14. Cerrar sesión

La aplicación mantiene la sesión del usuario activa para evitar una autenticación constante, brindando una experiencia fluida y cómoda.

No obstante, el usuario cuenta con la opción de cerrar manualmente su sesión.

**Cómo cerrar sesión:**

1. Ingresar a la sección **Perfil** desde la barra de navegación inferior.
2. Desplazarse hasta la opción **"Cerrar sesión"**.
3. Presionar el botón y confirmar la acción.
4. El sistema cerrará la sesión activa y redirigirá al usuario a la pantalla de inicio de sesión.

Para volver a ingresar, el usuario deberá autenticarse nuevamente con sus credenciales (Google o correo electrónico).
